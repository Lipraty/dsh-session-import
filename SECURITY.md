# Security and privacy

Do not post real session archives, converted DSH copies, model credentials, profile configuration, database files or complete logs in public issues. Transcripts may contain source code, prompts, tool output, account-specific URLs and secrets even when their filename looks harmless.

For ordinary bugs, include versions, the source harness, platform, a sanitized error and the smallest necessary anonymized excerpt. Unsupported source formats are expected to fail closed; never repair them by pasting credentials or loading an upstream runtime.

For a security-sensitive report, use GitHub private vulnerability reporting if it is enabled for this repository. Otherwise contact the maintainer privately rather than publishing exploitable details or private data in an issue.

This plugin does not execute historical tool calls. Imported content is nevertheless untrusted history: review it before using it in a new Agent conversation. Read-only source access does not mean the history has been redacted or is safe to share.
